# 玄译 · XuanYi
<p align="center">
  <img src="XuanYi.png" width="128" alt="玄译图标">
</p>
只提供：读取游戏聊天、在独立窗口显示原文和双语译文、手动填入游戏聊天正文。
中文先翻译为英文，英文直接填入；不自动回复、不切换频道或私聊对象、不按 Enter 发送。
不包含 XuanShu 的自动战斗、跑任务、采集、钓鱼、账号管理等功能。
界面沿用 XuanShu 当前的深色配色、圆角无边框标题栏和 Segoe UI 9 号字体；
中文使用系统字体回退，不分发 Windows 字体。底部右侧标注“作者:炙逸”。
复选框使用玄枢同款的勾选样式；标题栏左侧图钉按钮切换置顶，旁边齿轮配置 API。

## 使用

1. 启动游戏、进入角色，展开游戏聊天记录。
2. 运行 `dist/XuanYi.exe`（Windows 会请求管理员确认），选择游戏窗口，点击“开始读取”。
3. 在“API 设置”填写自己的接口、模型和 Key；勾选“自动翻译收到的聊天”后才自动调用接口。
4. 在游戏里选择频道和私聊对象，展开聊天**输入栏**，确保草稿为空。
   在玄译输入消息，点击“翻译并填入”或回车，只填入正文。最后在游戏里检查频道、对象和正文后自行发送。
   收到的消息中英双向翻译；填入的中文固定译成英文。消息/译文最多 80 个可打印字符，
   不支持换行或 emoji；不会截断长译文、覆盖已有草稿、重试输入或自动打开游戏输入栏。

接口正文会发送到你配置的服务，可能收费。开启读取时仅建立历史基线，不重放/翻译旧记录。
收到消息的翻译队列最多 32 条，过期/超量时仍保留原文；相同正文缓存复用，接口失败不自动重试。
游戏记录中标为“你”、不含玩家 GID 链接的本机消息只显示原文，不再自动翻译；
其他玩家发送相同正文仍可翻译。手动填入中文时仍先翻译成英文。
译文只显示在本软件窗口，不使用之前未成功显示的“原生聊天框追加”试验。
“已填入”只确认本地正文回读成功，不表示发送成功或对端收到。

## 游戏连接与权限

独立读取需要根窗口 Hook：连接库临时改写相关读取指令，在正常退出时撤销自己的连接。
**聊天内容只读不等于整个连接过程完全不写内存**。不启用 player/duel/teleport/自动战斗 Hook。
手动填入时才启用输入坐标支持，点击时暂时使用库的鼠标连接，结束后撤销鼠标连接。
若检测到其他工具已经建立了相同根窗口 Hook，会复用它**只读**，不会重复注入或撤销它。
为避免点击/频道冲突，复用连接时禁止手动填入；如需填入，请退出其他注入工具，
停止本软件读取后重新开始。不要强制结束正在连接游戏的程序；正常退出会清理自己的 Hook。
异常退出后若连接不可用，请重启游戏。不要把该程序用于违反游戏服务规则的场景。

## 密钥与发布

独立配置位于 `%APPDATA%/XuanYi/settings.json`。
首次运行兼容读取旧独立版 `%APPDATA%/Wizard101ChatTranslator/settings.json`；
保存时写入新目录，不覆盖或删除旧配置。新目录已存在配置时以新配置为准。
Key 由当前 Windows 用户用 DPAPI 加密；默认没有 Key，也不读取或复制 XuanShu 的个人设置。
当前打包清单不包含用户设置、`.env`、测试诊断或原项目配置。
发布 EXE 时不要另外附上个人设置/凭据。公开接口地址和模型名不属于密钥。
分发源码/修改版时请保留 LICENSE、NOTICE，并按 GPL 提供相应源代码。

## 运行源码或重新打包

当前机器可直接双击 `启动玄译.bat` / `玄译打包.bat`，优先使用本目录 `.venv`，
没有时只借用兄弟目录 XuanShu 的 Python 环境，不导入原主程序。

其他开发机器需要 Windows x64、Python 3.13：

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

然后使用 `玄译打包.bat`。输出只有本目录 `dist/XuanYi.exe`，不清理或覆盖原 XuanShu 项目。
测试不连接游戏、不发送真实聊天，也不调用收费 API。

模拟测试和 EXE 内容检查不等于真实游戏填入成功。版本升级可能改变 Hook 签名、
界面控件；遇到无法确认的状态会停止该次填入。频道/私聊对象和最终发送由用户在游戏里确认。
